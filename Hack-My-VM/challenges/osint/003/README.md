# HackMyVM - OSINT Challenge 003

## URL

https://hackmyvm.eu/challenges/challenge.php?c=003

## Concept

This challenge demonstrates a basic **OSINT (Open-Source Intelligence)** technique: gathering information about a person by analyzing and searching an image using publicly available sources.

The challenge highlights how information associated with an image can potentially be used to identify or learn more about a person.

## Method of Solve

1. Open the challenge page.
2. Download the image provided with the challenge.
3. Use the image with a reverse image search or another suitable search engine.
4. Analyze the search results to identify information about the person in the image.
5. Use the discovered information to determine the required flag.
6. Submit the flag to complete the challenge.

## Flag

```text
HMV{REDACTED}
```

## Key Takeaway

Images can contain or be associated with publicly available information that can be leveraged during OSINT investigations. Reverse image searching is a useful technique for discovering related sources and identifying contextual information.
