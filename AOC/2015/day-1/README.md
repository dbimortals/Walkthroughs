# Advent of Code 2015 - Day 1

## Part 1

Santa starts on floor `0`.

- `(` means go up one floor.
- `)` means go down one floor.

The solution calculates the final floor after processing all instructions.

## Part 2

The solution finds the position of the first character that causes Santa to enter the basement, which is floor `-1`.
